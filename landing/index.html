// features

Everything your on-call needs. Nothing it doesn't.

OpsAgent handles the toil: reading runbooks, generating remediation steps, and routing approvals — so your engineers can focus on the things that actually require human judgment.

⚡
Sub-5ms webhook ingestion
Webhook returns immediately. All RAG + LLM processing runs async via Celery + Redis. Your alerting pipeline never blocks.
OSS CORE
🔍
Hybrid RAG retrieval
pgvector dense embeddings fused with BM25 keyword search via Reciprocal Rank Fusion. Finds the right runbook section even when wording doesn't match exactly.
OSS CORE
🤖
Multi-LLM router
Gemini → Claude → GPT-4o fallback chain with A/B routing by incident ID. Low-confidence drafts are automatically flagged in Slack before you approve.
OSS CORE
🛡️
Safe execution engine
Blocked patterns at catalog-load time (rm -rf, DROP TABLE). Dry-run before every live action. subprocess exec with no shell=True. Full rollback on failure.
OSS CORE
📊
Observability built-in
9 Prometheus metrics, 10-panel Grafana dashboard, OpenTelemetry traces to Jaeger. RAGAS scores logged to MLflow. Ship it and you're already observable.
OSS CORE
🔐
SaaS auth + billing
JWT Bearer auth, Redis sliding-window rate limiting by tier, Stripe checkout + webhook handler. Kubernetes HPA scales on queue depth. Terraform for GCP.
